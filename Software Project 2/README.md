# Software Project 2: GamiLiDAR Simulated Forest Scanning

This is the poster and demo video of the project produced during the Tampere University course Software Project 2 in spring 2025. The project was made in group of 6 where part of the students were acting as senior developers and the rest as junior developers depending on experience. I worked as a senior developer / test manager in this project.

## Subject
The product we made is a simulation environment for testing GamiLiDAR Gamified augmented reality applications. Our customer for the project was a research group GamiLiDAR from Tampere University that develops mobile applications for gamified forest and environment scanning utilizing LiDAR scanners from mobilephones.
Our task was to develop a virtual testing environment for those applications where the research group could try out, test and develop their mobile applications without the need to setup a mobile device and go to an actual forest every time the application needs to be run. As a proof of concept we also developed a small 
prototype game that can be played in the simulation environment.

The ![demo video](demo.mp4) from our groups final presentation showcases the simulation environment and the game as well as how to use it. The video shows how the user can move around and scan the environment, saving scanned data points for later use. 
The prototype UFO shooting game is shown in the later part of the video.
